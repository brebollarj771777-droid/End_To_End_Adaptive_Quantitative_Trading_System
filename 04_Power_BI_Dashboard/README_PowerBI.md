# Quantitative Trading System Analytics with Power BI Dashboard

Interactive institutional dashboard designed to evaluate performance metrics, equity trajectory curves, risk management indicators, and operative signals generated by the Neural Network trading pipeline.

--

## Dashboard Overview & Visual Architecture

![Dashboard Preview](Dashboard_Preview.png)

The dashboard is structured in three main sections:

### Main Executive View

1.1. **KPI Performance Scorecard:**
   - **Cumulative Neural Net Return**: Total net return percentage achieved by the strategy.
   - **Cumulative Benchmark Return**: Buy-and-hold benchmark baseline return.
   - **Performance Spread (Alpha)**: Net outperformance margin against the market.
   - **Directional Accuracy**: Proportion of correct directional market calls made by the GRU model.
   - **Gross & Net Monetary Return**: Absolute portfolio gains calculated over a $100,000 initial investment base.
   - **Total Financial Costs**: Aggregated trading fees, leverage interest rates and asset borrow fees.

1.2. **Equity Curve Trajectory (Neural Network vs Benchmark)**
  - Dynamic chart comparing compound equity curves of the Neural Network strategy against the market benchmark across selected assets, sectors, and asset classes.

1.3. **Operative Signals For Investing Advice**
  - Real-time indicator panel presenting current asset position recommendations (Long (1), Short (-1), Cash (0)), active dynamic leverage levels (1.0x to 2.0x), and short-term tendency.

## Data Model & DAX Logic

This Power BI data model follows a Star Schema centered around the backtesting results table (`Datos_Estrategia`), connected to a dimensional table (`Dim_Activos`).

### Key DAX Measures

Below are the primary measures driving the quantitative analytics:

#### 1. Default Initial Investment Parameter
```dax
Initial Investment = 100000
```

### 2. Strategy Net Cumulative Return (% and MXN)

```dax
Rendimiento Acumulado de Estrategia = 

-- Calculate the gross cumulative return and substract financial costs to obtain the net monetary return

SUMX(
    VALUES(Dim_Activos[Ticker]),
    VAR Ultima_Fecha = CALCULATE(MAX(Datos_Estrategia_Benchmark[Fecha]))
    RETURN
        CALCULATE(
            MAX(Datos_Estrategia_Benchmark[Rendimiento_Acumulado_Estrategia]), 
            Datos_Estrategia_Benchmark[Fecha] = Ultima_Fecha
        )
)

Rendimiento Monetario Neto = [Rendimiento Monetario Obtenido] - [Costo Financiero Total]
```

### 3. Benchmark Cumulative Return

```dax
Rendimiento Acumulado de Benchmark = 

-- Calculate cumulative benchmark return for subsequent comparison with strategy

SUMX(
    VALUES(Dim_Activos[Ticker]),
    VAR Ultima_Fecha = CALCULATE(MAX(Datos_Estrategia_Benchmark[Fecha]))
    RETURN
        CALCULATE(
            MAX(Datos_Estrategia_Benchmark[Rendimiento_Acumulado_Benchmark]), 
            Datos_Estrategia_Benchmark[Fecha] = Ultima_Fecha
        )
)
```

### 4. Performance Spread (Alpha)

```dax
--- Calculate the spread between the cumulative strategy return and benchmark return, determine if strategy succesfully outperformed the benchmark

Diferencia De Rendimiento (Alpha) = [Rendimiento Acumulado de Estrategia] - [Rendimiento Acumulado de Benchmark]
```

### 5. Directional Accuracy

```dax
Ratio De Precision Del Modelo = 

-- Determine the percentage of days where the model succesfully predicted the benchmark's position.

VAR Dias_Contados = CALCULATE(COUNTROWS(),Datos_Estrategia_Benchmark[Posicion_Estrategia] <> 0)
VAR Dias_Correctos = CALCULATE(COUNTROWS(), Datos_Estrategia_Benchmark[Posicion_Estrategia] = 1 && Datos_Estrategia_Benchmark[Rendimientos_Diario_Benchmark] > 0 || Datos_Estrategia_Benchmark[Posicion_Estrategia] = -1 && Datos_Estrategia_Benchmark[Rendimientos_Diario_Benchmark] < 0)
RETURN
DIVIDE (Dias_Correctos,Dias_Contados,0)
```
